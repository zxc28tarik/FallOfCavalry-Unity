# Implementation 14A Scope

Authority is the user-approved Implementation 14A package on base `4c32c84e0a84ae0d4695fa927af195f2c375b08a`. The package is limited to historical regional geography, deterministic world travel, the map vertical slice, v13 persistence, Development bootstrap and their validation evidence.

Included: İstanbul-centered Marmara/Thrace content, explicit road/sea/crossing graph, typed immutable definitions, stable projection, Character/Army/Caravan travel, Envoy/Messenger ports, AI travel adapter, information-safe map projection, original decorative map art, slice-scoped fictional Sipahi player and focused tooling/tests.

Excluded: Implementation 14B city/character/economy/military historical content, final travel balance, weather/season, naval simulation, road construction, dynamic control, fog-of-war expansion, encounter content and battle implementation. Existing City V2 nine-area semantics and all prior invariants remain unchanged.
