# Implementation 11 — AI / Decision-Making

Implementation 11 establishes the production decision foundation. It does not add final historical profiles, balance values, world pathfinding, siege/naval AI, deep intrigue, presentation, or scripted outcomes.

The scope is locked to deterministic utility evaluation, explicit Character/Faction decision owners, report-bound perception, data-driven priority/personality/decision-quality profiles, proposal-to-existing-service execution, strategic plans, event/time scheduling, low-importance work sharing, tactical BattleOrder integration, save schema v12, validation, tests, and measurement.

The fairness contract is non-negotiable: AI uses the same rules, resources, authority, information, travel, supply, diplomacy, trade, recruitment, contract, encounter, and battle-order constraints as every other caller. Difficulty changes decision work quality only. No production balance numbers were selected; every shipped numeric AI fixture is named and marked `PROOF_ONLY`.

Implementation 12 is not part of this change.
