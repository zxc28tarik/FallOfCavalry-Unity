Adaptation
- Whole clothed humanoid: 9,586 source triangles, one skin, 23 source bones.
- Preserve source geometry, bone hierarchy, bind transforms and skin weights.
- Add semantic FOC sockets as child markers, not replacement deformation bones.
- Explicit Unity Humanoid mapping: source Chest -> Human Spine, source
  UpperChest -> Human Chest; retain all source transforms.
- The supplied FBX's saved object pose is Running, not its original bind pose.
  Derive the reference/prefab pose from existing skin bind matrices. Do not
  create a new rig or bake that Running pose into the Avatar reference.
  The pilot prefab stores the actual bind pose with Animator initially disabled;
  the review explicitly enables animation only when a real clip is requested.
- Imported weights are checked finite, normalized, and at most four influences.
  This is not a claim of bit-identical Unity floating-point weight values.
  A source audit found 946 tiny influences below 0.001 across 889/13520 source
  vertices. Unity clamps its minimum importer threshold to 0.001, so pruning
  and normalization are possible. Simulated maximum removed mass per affected
  vertex is 0.00167625 (0.167625%). Original source weights are not rewritten.
- Base color reduced from 8192 to 2048 for the pilot. Metallic and roughness
  reduced from 4096 to 2048 and packed for Unity Standard: RGB metallic,
  alpha = 1 - roughness. No invented normal map or flat replacement colors.
- Walking and Running are the only source clips. They must be tested as real
  Unity Humanoid animation, not renamed proof animation.

Integration boundary
The Meshy skeleton is NOT the FOC canonical 18-bone modular skeleton.
CanonicalRig/RigValidator remain unchanged and reject this foreign descriptor.
A valid Unity Human Avatar does not overturn that result.

The pilot uses its own transient Standard-only VisualCatalog and the existing
VisualSoldier3DAssembler/cache/pool. Body/head/clothing semantic slots alias one
indivisible consolidated character. Only ONE character mesh is instantiated;
Narrative and Crowd are explicitly unsupported to prevent duplicate geometry.
This is not yet interchangeable body/head/clothing production modularity.
Gameplay SoldierInstance, persistent loadout, deterministic signatures, domain,
save schema v14, and production historical catalog are unchanged.

Source limitations / pending production work
- Only one actual supplied LOD. LOD1/LOD2 are pending; no fake duplicate LODs.
- No finger bones. Hand sockets do not establish a correct weapon grip.
- No Idle, Attack, Crouch, mounted locomotion or seated animation was supplied.
- The existing proof shared library is not a production Humanoid muscle library;
  playing its transform clips is not evidence of successful retargeting.
- Mounted integration is deliberately rejected until pelvis/saddle alignment
  and actual mounted deformation are demonstrated.
- Sipahi, Cebeli and Tufekci replacements are not supplied by this pilot.
- Historical and final visual review are separate from technical import tests.
- 100/250/500-actor benchmarks and proof-versus-production comparison are not
  executed by the 12-actor pilot capture suite; no frame-rate claim is made.
